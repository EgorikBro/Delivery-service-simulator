# Практическое задание 1. Консольный симулятор службы доставки

Консольное приложение на Java, которое моделирует работу небольшой службы доставки:
создание заказов, выбор способа доставки, назначение курьера и ведение заказа по статусам.
Все данные хранятся только в памяти — без базы данных, файлов, сети и графического интерфейса.

## Возможности

- Создание заказа с данными клиента, адресом доставки и одной или несколькими позициями
- Просмотр списка существующих заказов
- Выбор способа доставки с расчётом стоимости и ориентировочного срока
- Назначение курьера, если выбранный способ доставки это предусматривает
- Изменение статуса заказа с проверкой допустимости перехода
- Обработка некорректного ввода с понятными сообщениями для пользователя

## Способы доставки

| Способ               | Стоимость                       | Срок         | Курьер    |
|----------------------|---------------------------------|--------------|-----------|
| Стандартная доставка | базовый тариф                   | несколько дней | требуется |
| Экспресс-доставка    | дороже стандартной              | быстрее стандартной | требуется |
| Самовывоз            | бесплатно                       | сразу после подтверждения | не требуется |

Каждый способ доставки реализует общий интерфейс DeliveryMethod и сам рассчитывает
стоимость и срок — код оформления заказа не зависит от конкретного типа доставки.

## Статусы заказа
```
CREATED → CONFIRMED → IN_DELIVERY      → DELIVERED
                    ↘ READY_FOR_PICKUP ↗   (самовывоз)

CREATED, CONFIRMED → CANCELLED
```
## Технологии

- Java 17
- Maven
- JUnit 5 (тесты)

## Сборка и запуск

Требуется установленная JDK 17+ и Maven.
```
mvn compile
mvn exec:java
```
Запуск тестов:
```
mvn test
```
## Структура проекта
```
src/main/java/delivery/
├── model/       сущности: Client, Courier, OrderItem, Order, OrderStatus
├── delivery/    контракт DeliveryMethod и его реализации
├── service/     бизнес-логика: OrderService, CourierRegistry
├── exception/   исключения бизнес-правил
├── ui/          взаимодействие с консолью: ConsoleUI, InputReader, OrderPrinter
└── Main.java    точка входа
```
## Работа с репозиторием

- Ветка main содержит только проверенный код; прямые коммиты в неё не делаются
- Каждая задача ведётся в отдельной ветке (feature/..., fix/..., docs/..., test/...)
- Изменения попадают в main через Pull Request после ревью второго участника
- Сообщения коммитов оформляются по [Conventional Commits](https://www.conventionalcommits.org/ru/v1.0.0/):
  feat:, fix:, refactor:, test:, docs:, chore:
